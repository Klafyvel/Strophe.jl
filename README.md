> for XMPP poets

Strophe.jl is a Julia binding for [`libstrophe`](https://strophe.im/), a C library for XMPP clients and components.

## Installation

Install the library from the REPL:

```julia-repl
julia> # press ]
pkg> add Strophe
```

## Low-level API

There is a low-level binding that closely maps the C API. Head to [the low-level API section](https://klafyvel.github.io/Strophe.jl/stable/low-level-api/) to learn more!
