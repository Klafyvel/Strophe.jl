Low-level API

The low-level API is a direct binding to the underlying libstrophe library.

libstrophe is a C library for XMPP clients and components. It has very minimal dependencies and was designed with both POSIX and Windows systems in mind.

libstrophe's manual

Attribution of the low-level API documentation

This part of the documentation is mostly a port of the original C library documentation, with some adaptations made for Julia, especially in the examples. All credit goes to the libstrophe contributors.
