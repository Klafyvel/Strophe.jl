# [Low-level API](@id low-level-api)

The low-level API is a direct binding to [the underlying libstrophe library](https://strophe.im/libstrophe/doc/0.13.0).

> libstrophe is a C library for XMPP clients and components. It has very minimal dependencies and was designed with both POSIX and Windows systems in mind.
[libstrophe's manual](https://strophe.im/)

!!! note "Attribution of the low-level API documentation"
    This part of the documentation is mostly a port of [the original C library documentation](https://strophe.im/libstrophe/), with some adaptations made for Julia, especially in the examples. All credit goes to the libstrophe contributors.
